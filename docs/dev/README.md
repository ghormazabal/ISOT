# Documentación para desarrolladores

Para quien hace un fork de ISoT o continúa su desarrollo. La documentación de
uso está en el [README](../../README.md); las guías para agentes en
[AGENTS.md](../../AGENTS.md).

| Documento | Contenido |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | Piezas (API, CLI, reglas, renders, config multi-repo, ingesta, frontend), flujo de datos y **por qué** está diseñado así |
| [FILES.md](FILES.md) | Mapa archivo por archivo: qué hace cada módulo y sus funciones/exports principales |
| [CONTRIBUTING-DEV.md](CONTRIBUTING-DEV.md) | Entorno, ejecutar/testear/construir, cómo añadir una regla, un template de render, una ruta de API o una pestaña de la UI, convenciones, controles de fuga y flujo de merge |
